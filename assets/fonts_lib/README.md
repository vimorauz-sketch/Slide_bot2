# Font library

160 font families from [Google Fonts](https://github.com/google/fonts), downloaded unchanged by
`tools/fetch_fonts.py` (which also writes `catalog.json`). Each family is licensed under the
SIL Open Font License 1.1, the Apache License 2.0 or the Ubuntu Font Licence, as stated in the
`ofl/`, `apache/` and `ufl/` folders of that repository — all allow free use, embedding in PDF files
and redistribution to customers together with their presentations.

Only families that draw Uzbek Latin completely are kept; `cyrillic: true` marks those that also
write Russian.
